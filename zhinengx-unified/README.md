# 知能行合体助手 · 本地验收

安装文件为 `zhinengx_unified.user.js`。一个文件提供原有的美化面板、做题操作、复制、倒计时、报告导出和数据图表。合并前的功能基线为 `ab81e2b`。合并版采用独立的 `10.0.0` 版本线，当前底栏为 `10.0.0-dev.2.1`，首次公测为 `10.0.0-beta.1`，首次正式发布为 `10.0.0`。

项目包含四个用户脚本。合并版在 `master` 开发，[独立美化](../zhinengx-beautifier/zhinengx_beautifier.user.js)和[独立导出](../zhinengx-exporter/zhinengx_exporter.user.js)继续在 `develop` 并行维护，[快照脚本](../dev_resources/snapshots/capture.user.js)沿用自己的版本线。

## 安装、升级和回退

1. 在此目录运行 `node serve.cjs`，在装有 Tampermonkey 的浏览器打开 [本机安装入口](http://127.0.0.1:18767/zhinengx_unified.user.js)。服务仅监听回环地址，每次请求都读取当前源码。安装后可按 Ctrl+C 关闭服务。
2. 新用户安装一次即可。旧用户若希望恢复手头的具体安装版本，先在油猴实用工具中备份旧美化脚本。合体文件沿用其名称、命名空间和基线脚本头。油猴识别已有同名安装。本次已装头版本为 `8.4.1-beta.1`，安装页对分支头版本 `8.4.0-beta.1` 显示 **Downgrade**。有同版本时也需要手动确认安装。
3. **首次刷新站点前**，启用合体助手，停用旧独立导出器，并停用另行安装的美化、导出 DEV 存根。确认每种功能只有一个启用来源，再刷新模块页。可在当前科目直接点「导出报告」。若提示另一科目明细不全，在同一标签切换到该科目并刷新，以补充缓存。
4. 回退时先停用合体测试条目。如覆盖了旧美化条目，从备份恢复，或安装仓库中的 [基线美化助手](../zhinengx-beautifier/zhinengx_beautifier.user.js)。重新启用 [原导出器](../zhinengx-exporter/zhinengx_exporter.user.js)，再刷新。原先通过两个 DEV 存根使用的，可直接恢复两个存根。沿用原站点和浏览器配置，保留设置、卡片位置以及当前标签的 sessionStorage。

## 本地调试与回归

修改单文件后，重新打开本机安装入口，确认安装并刷新模块页。需要保存即刷新时，可在油猴另建 DEV 存根，沿用交付文件的两个 `@match`、`@run-at document-start` 和 `@grant none`，用 `@require file:///.../zhinengx-unified/zhinengx_unified.user.js` 指向本地绝对路径。开启扩展的「允许访问文件网址」，仅启用该存根进行调试。调试存根的 `@name` 以 `[DEV]` 开头，开发版底栏会显示源码版本和保存时间。首屏时序验收使用直接安装。

`startExporter()` 在 HTTPS 页面启动时注册 fetch 和 XHR 监听。`onDomReady()` 安排两个模块各自的界面初始化。`mountBeautifier()` 保留美化功能自身的事件与设置。`copyText()` 统一提供原生剪贴板、隐藏文本框兼容复制、手动复制弹窗。

用 Node.js、Git、本机 Chrome 和 Playwright Core 运行 `node regression.cjs`。可用 `NODE_PATH` 指向包含 playwright-core 的 node_modules。本机 PowerShell 可在此目录执行：

```powershell
$env:NODE_PATH = "$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules"
node regression.cjs
```

在包含基线提交 `ab81e2b` 的完整 Git 检出中，从 `zhinengx-unified` 目录执行上述命令。测试输入为仓库内的 `fixtures/choice.html`、`fixtures/blank.html`、`fixtures/profile.json` 和 `dev_resources/copy-solution-test.html`。两版读取同一组合成题卡和进度数据。Chrome 使用临时配置，页面请求由测试拦截，退出码 0 表示整套通过。

## 10.0.0-dev.2.1 本地验证

- **修复**　训练页「复制题目」优先提取题干正文，收藏星标不会混入 Markdown。保留真实题图、公式和选项顺序。
- **已知问题**　快照回放中的复制文本为正常中文。原粘贴应用内的乱码仍待实测。

## 10.0.0-dev.1.3 本地验证

- **修复**　训练页「复制题目」对仅有可读文本的 KaTeX 辅助节点保留数学定界符。用例检查 `问题 $x+1$`、块公式、带 MathML 的 AsciiMath、题图和选项顺序。解析弹窗继续拒绝缺少结构的公式。
- **修复**　ECharts 加载失败后，再点「数据图表」可重试。Chrome 拦截首次请求使其失败，重试期间连续点击，成功后关闭再打开。断言总请求数为 2，且大屏包含今天的图表数据。
- **优化**　选择题夹具刻意颠倒 DOM 和视觉顺序，验证数字键 2、回车单次提交及填空首字符聚焦和输入。进度夹具覆盖「今天」标志冲突、明确空数据、跨科、跨日和跨周。报告与双脚本基线逐字符对照，仅排除已修复的「今天」段落。
- **已知问题**　沿用旧脚本头时，部分公测用户手动安装会看到降级提示。本轮使用隔离 Chrome 和模拟 CDN 响应，真实站点与油猴体验记录见下表的历史实测列。
