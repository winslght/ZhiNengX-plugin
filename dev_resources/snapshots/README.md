# 📸 页面快照收集器 v2.0

> **一句话**：开着它正常做一次题，它会把每一个界面状态自动拍下来；点一下导出，得到一个可双击打开的合集文件——**以后修 bug、验证改动，都在这个文件里做，不再需要重做一小时题**。

---

## 1. 装了怎么用

### 方式 A：装进 Tampermonkey（推荐，一次装好长期有效）

1. 复制 `capture.user.js` 全文
2. Tampermonkey → 添加新脚本 → 粘贴覆盖 → `Ctrl+S` 保存
3. 使用 Chrome 或 Edge 打开知能行页面，点击左下角 `📸`，选择「选择保存文件夹」
4. 在文件夹选择窗口中选中本地仓库的 `dev_resources/snapshots/inbox`，并允许写入
5. 手动或自动拍摄后，单张 HTML 会写入该文件夹，导出合集也写入同一目录。刷新或重启浏览器后如提示权限失效，点击「恢复写入权限」

> 已安装的旧版（v1.x 的 `capture.js`）已合并进本文件，请删除旧脚本，避免两套 UI 打架。

### 方式 B：临时粘贴到 Console

`F12` → Console → 粘贴 `capture.user.js` 全文 → 回车。能力完全相同，但刷新后失效。
（首次粘贴需手打 `allow pasting` 回车一次。）

## 2. 热键

| 热键（Shift 或 Alt 均可） | 作用 |
| :--- | :--- |
| `Ctrl+Shift+S` / `Ctrl+Alt+S` | 拍下当前状态，存进本地快照库并写入所选文件夹 |
| `Ctrl+Shift+A` / `Ctrl+Alt+A` | 开关**自动连拍**（默认关） |
| `Ctrl+Shift+D` / `Ctrl+Alt+D` | 保存**单张**快照至所选文件夹（自包含 HTML，等同旧版用法） |
| `Ctrl+Shift+E` / `Ctrl+Alt+E` | 导出**合集**（所有状态打包成一个文件） |
| `Ctrl+Shift+X` / `Ctrl+Alt+X` | 清空本地快照库（二次确认） |

> 为什么给两套修饰键：`Ctrl+Shift+A/S/E/D/X` 有几个被 Chrome 或 Edge 占用（如「搜索标签页」「网页捕获」）。被吞了就用 `Ctrl+Alt+*`。

左下角徽标点一下也有同样功能的按钮面板。

---

## 3. 三种工作流

### ① 自动录一遍（主力，解决"状态随做题出现"）

1. `Ctrl+Shift+A` 打开自动连拍
2. 像平常一样做题，该点弹窗就点、该切页面就切
3. 每次页面内容稳定约 3 秒且与上一张不同，就自动存一张
4. 做完 `Ctrl+Shift+A` 关掉，`Ctrl+Shift+E` 导出

同一状态会自动去重；上限 80 张，到顶会自动停并提示导出。

### ② 手动补拍（针对某个瞬间）

看到怪界面直接 `Ctrl+Shift+S`。适合：hover 态、弹窗刚开、刚判对错。

### ③ 单张下载（要发给别人 / 只想看一个状态）

`Ctrl+Shift+D` 得到 `znx_20261116-2015_exam_1184x949_plugin.html`，双击即开。

## 4. 合集文件里能干什么

打开 `znx-bundle_20261116-2020_12shots.html` 后，底部有一条工具栏：

| 操作 | 效果 |
| :--- | :--- |
| `◀` / `▶` 或 `[` `]` | 在 12 个状态之间切换 |
| 下拉框 | 直接跳到某个状态（显示路径；未加载插件时标注「无插件」） |
| `切到原版` 或 `R` | 在「插件后 / 原版」两棵 DOM 之间切换 |
| 地址加 `?i=5` | 直接打开第 5 个状态 |

切换会**同时**替换页面的样式表与根节点，所以每个状态都是完整独立的画面，不是"只换内容、样式串味"。

---

## 5. 每张快照里存了什么

| 内容 | 用途 |
| :--- | :--- |
| **插件后 DOM** | 你拍照那一刻的真实画面 |
| **原版 DOM** | 减去插件新增节点 / 属性 / class / 注入样式后的站点原生状态 |
| **插件产物清单**（JSON） | 新增了哪些节点（含 `nested` 标记）、给原节点加了哪些 `data-znx-*` / class、注入了哪几段 `<style>`、多少条规则 |
| **公式真值表**（JSON） | 页面里每个公式的 TeX 源码（MathJax 走 `MathJax.Hub.getAllJax()`，KaTeX 走 `annotation`），用于校验「复制题目/解析」的输出对不对 |
| **环境参数** | URL、视口、DPR、滚动位置、Dark Reader 状态、html class、UA、插件设置 |
| **资源清单** | 本次加载的 CSS / JS（判断是不是某个 CDN 拖慢了公式渲染） |
| **可交互元素清单** | 页面上的 dialog 标题、按钮文案，用来判断"还差哪些状态没拍" |

报告在 `<script type="application/json" id="znx-snapshot-report">`（单张）或 `id="znx-bundle-meta"`（合集）。

---

## 6. 原版视图的原理与边界

插件是**叠加式**改法：加节点、加 `data-znx-*`、加 `znx-*` class、另插一条 CSS 规则，**不删也不改写站点原节点**。所以「减掉插件产物」就能还原原版，且切换时会把 `style[data-znx-plugin-style]` 整段禁用。

⚠️ 如果将来插件改成直接覆盖站点元素的 `style.xxx`，被覆盖的原值无法恢复——那种写法要避开。

## 7. 数据存在哪 / 隐私

- 快照同时保存在浏览器的 **IndexedDB**（库名 `znx_snapshot_db`）和选定文件夹，不上传。不同网站域名需分别选择文件夹并授权。
- 快照里含头像、用户名、做题记录、页面文本。**导出后请勿上传公开仓库**；`inbox/` 已在 `.gitignore` 中。
- 自动连拍会把你浏览时的页面存下来，公用电脑上用完请 `Ctrl+Shift+X` 清空。

---

浏览器限制脚本直接指定本机绝对路径，因此首次必须手动选择 inbox。若写入失败，拍下的记录仍在浏览器快照库中，可恢复权限后导出合集。

## 8. 排错

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| 提示恢复写入权限 | 浏览器重启后权限可能失效 | 打开面板，点击「恢复写入权限」 |
| 左下角没有 `📸` | 脚本未生效 / 域名不匹配 | 确认 TM 里脚本已启用；确认在 `bestzixue.com` 或 `zhinengxing.com` |
| 打开快照只有「加载中...」 | 拍的是未渲染页面，或站点脚本没剥掉 | 页面加载完再拍；确认用的是最新版脚本 |
| 打开快照没样式 | CSS 抓取全失败（CSP/断网） | 看 Console 回执的内联 CSS 数量；联网后重拍 |
| 原版与插件后长得一样 | 拍照时插件未生效 | 看报告 `plugin.active`；文件名后缀是 `_clean` 就是没插件 |
| 合集文件很大 | 每个状态都带一份完整 CSS + 两棵 DOM | 正常，10 个状态约 6～15 MB；导入时浏览器会卡 1～2 秒 |
| 自动连拍没反应 | 内容一直在变（有计时器在跳） | 关掉做题倒计时或改用 `Ctrl+Shift+S` 手动拍 |
| 导出失败 / 无响应 | 状态太多导致字符串过大 | 先导出、再清空；或分批（拍 10 张就导一次） |

---

## 9. 拍不到什么（别指望错地方）

- 后端返回的题目 JSON（除非另做网络录制）
- 点击 / hover / focus 之后的**行为**（快照是静态的，事件全死）
- 动画中间帧、`setInterval` 内部状态
- Canvas / WebGL / Live2D 画面
- 跨域 iframe 内部
- 拍照之前发生的控制台报错

## 10. 自检

本工具自带两份静态自检（不需要浏览器，改完脚本先跑一遍）：

```powershell
node dev_resources/snapshots/selfcheck.js
```

它会验证：内嵌 CSS/JS 语法、双视图模板 id 一致性、模板引用是否被缓存、合集 head 去重、报告 JSON 可解析、HTML 注释转义是否安全。
