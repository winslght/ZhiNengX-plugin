# 📋 发布日志与更新卡片模版 (Release Card Template)

> **使用说明**：在每次发布新版本或更新 GitHub Release / GreasyFork 提交日志时，直接复制下文模版，并填写对应的版本号、修复痛点、新增变动、已知 BUG 矩阵及下版 Roadmap 即可。

---

```markdown
# 🚀 ZhiNengX Release vX.Y.Z 更新发布日志

## 📌 一、 本次更新背景与解决的前版痛点
> **修复背景**：说明为什么发布这个版本（如：上一版本 vX.Y.W 存在什么 BUG / 痛点 / 用户反馈问题）。
> **期望目标**：本次更新旨在解决上述问题，并达到什么预期效果。

---

## ✨ 二、 本次更新明细 (Changes)

### 🎨 美化插件 (Beautifier vX.Y.Z)
- **【New】**: 新增了 xxx 功能。
- **【Fix】**: 修复了上版本中 xxx 的 BUG。
- **【Opt】**: 优化了 xxx 样式的性能与响应速度。

### 📊 导出插件 (Exporter vA.B.C)
- **【New】**: 新增了 xxx 诊断大屏图表。
- **【Fix】**: 修复了数二/数三模块筛选中的 xxx 异常。

---

## ⚠️ 三、 当前版本已知 BUG 与临时规避方案 (Known Issues)

| ISSUE ID | 缺陷现象描述 | 触发场景 | 严重等级 | 临时规避方案 (Workaround) | 预计修复版本 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `ISSUE-01` | [问题简单描述] | [触发条件] | P2 (低) | [用户可采取的临时规避措施] | vX.Y.Z+1 |

---

## 🔮 四、 下一版本规划与 Roadmap (Next Version)
- [ ] 计划在下版本加入 xxx 功能。
- [ ] 计划进一步攻克 xxx 已知问题。
```
