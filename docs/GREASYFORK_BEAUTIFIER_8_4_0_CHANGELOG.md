## 8.4.0 正式版

### 修复

- 保留能力进度条原生渐变与考研倒计时配色。
- 点击「想看答案」打开确认框时，底栏不再误变红，真实判题反馈仍显示对应颜色。
- 恢复训练及复盘中的题解复制入口，补全 MathJax SVG 公式提取，避免部分公式丢失或重复。
- 数字键按屏幕顺序选择选项，回车可提交或继续。

### 优化

- 统一普通选项与题干的毛玻璃效果，并调整训练成功页、「温故知新」「突破口」、账号设置页及「完成测试」弹窗的底色。
- 将淡橙色的「复制题目和解析」按钮移到「关闭」左侧。

### 新增

- 支持复制包含题目、解析、LaTeX 和题图链接的 Markdown。原题折叠时提示先展开。

### 已知问题

- 缺少 TeX 源码且使用暂不支持的 MathML 结构时，复制会提示失败。
- 真实网页的完整复制流程和复杂题图访问仍待实测。
