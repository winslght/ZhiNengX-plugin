## 🚀 需求与优化规划池 (Feature Backlog & Roadmap)

### 📌 优先级定义：
- **P0 (紧急)**：阻碍正常做题或数据导出的崩溃级问题（24小时内响应）。
- **P1 (重要)**：核心体验提升，预计在下一个次版本中发布。
- **P2 (一般)**：次要功能优化、样式微调或长远探索特性。

### 🎨 美化插件 (Beautifier) Roadmap

- [ ] **[P1] 自定义考研目标倒计时**：允许用户在设置面板中自定义目标考试日期（如 2027、2028 或自定义月/日）。
- [ ] **[P1] 主题颜色预设一键切换**：内置【黑曜石】、【翡翠绿】、【深海蓝】、【紫罗兰】四套原生样式模板。
- [ ] **[P2] 看板娘互动增强**：新增悬停语音/文字提示及更多 Live2D 动作。
- [ ] **[P2] 单独立体音效感应**：提交做对/做错时支持可选播放清脆提示音。

---

### 📊 导出插件 (Exporter) Roadmap

- [ ] **[P1] 诊断大屏图表一键导出图片**：在 ECharts 图表右上角增加一键保存高清 PNG 图表按钮。
- [ ] **[P1] 章节弱点树状展开**：在 Markdown 报告中支持按“高数/线代/概率”三层树状展开详细错误错题集。
- [ ] **[P2] 诊断数据对比分析**：支持导入上一次导出的 Markdown 报告，自动生成能力提升对比图。
